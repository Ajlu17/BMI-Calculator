# BMI Calculator

A simple graphical BMI calculator built with Python and Tkinter.

## Requirements

- Python 3
- Tkinter (included with most Python installations)

## Usage

Run the program from this directory:

```bash
python bmicalculator.py
```

Enter your weight in pounds, height in feet, and any additional inches.
Click **Calculate BMI** to display your BMI.

The calculator uses the standard BMI formula for measurements in pounds and inches:

```text
BMI = (weight / height²) × 703
```
